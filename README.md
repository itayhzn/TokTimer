# TokTimer project page

Static project page for *TokTimer: Per-Token Denoising Time for Enhanced Prompt Alignment in Flow-Matching Diffusion Models*.

- `index.html` — the page (no build step; open directly or serve with GitHub Pages).
- `assets/` — figures extracted from the paper (`teaser/`, `qualitative/`, `ablation/`, `sensitivity/`).
